# Riftbound — Règles de tournoi et sanctions juge (résumé)

Source officielle : **Riftbound Tournament Rules, mise à jour du 2026-07-16**
- Page officielle : https://playriftbound.com/en-us/news/organizedplay/riftbound-tournament-rules/
- PDF officiel : https://cmsassets.rgpub.io/sanity/files/dsfx7636/news_live/503da65669ced10598d62925a6f6bc15111af726.pdf
- Version navigable : https://app.riftjudge.com/rules/tournament
- Il n'existe pas de document "IPG" séparé : les infractions et sanctions sont la section 700 des Tournament Rules.

## Structure
000 Golden Rule · 100 Introduction · 200 Définitions · 300 Éligibilité · 400 Politiques · 500 Communication · 600 Formats · 700 Application et sanctions

## Niveaux d'application (OPL, 205)
- **Casual** (Low OPL) : pédagogie, sanctions légères.
- **Competitive** (High OPL) : joueurs censés connaître les règles.
- **Professional** (High OPL) : jeu techniquement précis, sanctions les plus strictes.

## Rôles (203-204)
Organisateur, **Head Judge** (autorité finale), Floor Judge, Scorekeeper. Le joueur doit maintenir un état de jeu clair et appeler un juge en cas d'erreur.

## Format de match
- **BO3** (404). Rondes suisses : **60 min** recommandées (604.1).
- Fin du temps (408) : le joueur actif finit son tour, puis **3 tours supplémentaires**. Ensuite : victoire au joueur avec **2+ points d'avance**, sinon partie nulle.
- Premier joueur (407) : le joueur désigné aléatoirement choisit ; en playoffs High OPL, le mieux classé du suisse choisit.

## Decklist et deckbuilding
- Decklist obligatoire en High OPL, non modifiable après remise (401) : Legend, battlefields, Main Deck 40 avec Chosen Champion, 12 runes, sideboard.
- **Sideboard : 10 cartes max**, échange 1 pour 1, pas en game 1 ; Legend, runes et battlefields fixes (403).
- **Battlefields** (602.3.e) : 3 enregistrés ; en BO1 tirage aléatoire ; en BO3 choix à chaque partie, chaque battlefield une seule fois par match.
- Légalité : set légal dans le format ou même nom qu'une carte légale ; cartes bannies interdites (601.2).
- Mélange aléatoire obligatoire et présentation à l'adversaire (421) ; mélange adverse en High OPL.

## Communication (500)
Info publique (tour, phase, scores, état des permanents, Chain, cartes recyclées) : réponse honnête obligatoire. Info dérivée : pas d'obligation d'aider. Triggers : à reconnaître avant leur impact observable, sinon oubliés (506.3). Raccourcis : à annoncer (503).

## Concessions et nuls (410)
Possibles à tout moment, jamais en échange de quelque chose, sans consulter d'autres résultats.

## Sanctions (701-704)
Types : **Warning**, **Game Loss**, **Match Loss**, **Disqualification**. Escalade : 3e Warning de la même catégorie → Game Loss ; au total 6 Warnings (Competitive) / 5 (Professional) → Game Loss.

### Erreurs de jeu (702)
| Infraction | Sanction | Remède principal |
|---|---|---|
| Missed Trigger (702.2) | Aucune (Warning si obligatoire et avantageux) | L'adversaire choisit : résoudre maintenant ou ignorer |
| Forgetting to Score (702.3) | Aucune | Corriger si détecté dans le cycle de tour |
| Forgetting to Draw (702.4) | Aucune (Warning si avantageux) | Piocher si dans le cycle de tour |
| Looking at Extra Cards (702.5) | Warning | L'adversaire choisit les cartes à remélanger |
| Channeling Too Many Runes (702.6) | Warning | Rembobiner / remélanger |
| Channeling Too Few Runes (702.7) | Aucune | Canaliser le manquant |
| Overpayment (702.8) | Aucune | Ressources en surplus restent dispo ce tour |
| Mispayment (702.9) | Warning | Rembobinage simple ou corriger le paiement |
| Looking at Secret Info (702.10) | Warning | Re-randomiser |
| Looking at Opponent Private Info (702.11) | Warning | L'adversaire peut re-randomiser |
| Drawing Extra Cards (702.12) | Warning | L'adversaire choisit les cartes à remélanger |
| Facedown Card Error (702.13) | Warning → Game Loss selon timing | Retour / remplacement |
| Mulligan Procedure Error (702.14) | Warning | Remulligan partiel |
| Forgetting to Ready (702.15) | Aucune | Redresser si même tour |
| General Error (702.16) | Warning | Rembobiner si possible |
| Failure to Maintain Game State (702.17) | Warning | Pour l'adversaire qui n'a pas relevé l'erreur |

### Erreurs de tournoi (703)
| Infraction | Sanction |
|---|---|
| Slow Play (703.2) | Warning (stalling volontaire = triche) |
| Decklist Error (703.3) | Game Loss |
| Deck Presentation Error (703.4) | Warning, Game Loss selon cas |
| Communication Violation (703.5) | Warning |
| Marked Cards (703.6) | Warning |
| Insufficient Randomization (703.7) | Warning |

### Conduite antisportive et triche (704)
Triche (704.8) : violation intentionnelle, abus des remèdes, provoquer des triggers manqués, boucles pour gagner du temps, angle shooting, scouting avant concession. → Disqualification.
