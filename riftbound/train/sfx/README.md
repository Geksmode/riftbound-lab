# Sons de la table

Fichiers MP3 tirés du paquet npm `uisfx` 0.4.0 (audio CC0 1.0, voir `LICENSE-AUDIO` ; code MIT non repris) : 6 ambiances
(`studio` par défaut, `cinematic`, `zen`, `soft`, `organic`, `glass`) et 21 sons chacune. La correspondance
« événement de la table → fichier » est dans `src.html` (`SFX`, table `MAP`). `build.sh` copie ce dossier dans `build/sfx/`.
Pour remplacer un son : garder le même nom de fichier dans chaque ambiance.
