# Carnet de parties

Une entrée par partie, juste après la partie, 2 minutes maximum. Après 10 parties, on relit tout pour
trouver les erreurs qui reviennent. Une partie seule ne prouve rien (voir [[Méthode statistique]]).

## Modèle à copier
```
### AAAA-MM-JJ · Tournoi/ligue · Manche 1/2/3
- Adversaire : légende, et cartes marquantes vues
- Qui commence : moi / lui
- Champs de bataille : le mien / le sien
- Main de départ : ... · mulligan : ...
- Score final : moi X - lui Y · victoire / défaite
- Tour clé : ce qui s'est passé
- Ce que je referais autrement :
- Classement : erreur / matchup / pioche
```
