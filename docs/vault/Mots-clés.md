## Bonus d'équipement (absents de la base de cartes)
Les bonus de Might des équipements sont une icône, non présente dans la base : **Long Sword +2**,
**Sterak's Gage +3**, **Pendulum Blade +1** (lus sur les cartes). **Zhonya's Hourglass** a un errata
(texte riftwatcher, différent de la base).
