# Règles de tournoi

Source : **Tournament Rules du 2026-07-16** ([page](https://playriftbound.com/en-us/news/organizedplay/riftbound-tournament-rules/),
[par règle](https://app.riftjudge.com/rules/tournament)). Pas de document « IPG » séparé : les sanctions sont
la section 700. Résumé complet : `riftbound/rules/tournament-rules-resume.md`.

## Format
- **BO3** (404), rondes suisses de **60 min** recommandées (604.1).
- Fin du temps (408) : le joueur actif finit son tour, puis **3 tours supplémentaires** ; ensuite victoire
  au joueur avec **2+ points d'avance**, sinon nul.
- **Premier joueur** (407) : le joueur désigné au hasard choisit ; en playoffs High OPL, le mieux classé du
  suisse choisit. Commencer est un avantage mesuré (voir [[Akali vs LeBlanc]]).
- Deckbuilding, sideboard et battlefields : voir [[Construction de deck]].

## Niveaux (OPL)
Casual (pédagogie), Competitive, Professional (sanctions les plus strictes).

## Communication (500)
Info publique (score, phase, état des permanents, chaîne, cartes recyclées) : réponse honnête obligatoire.
Triggers à reconnaître avant leur impact observable, sinon oubliés (506.3). Raccourcis à annoncer (503).

## Sanctions (701-704)
Warning → Game Loss → Match Loss → Disqualification. 3e Warning de la même catégorie = Game Loss ;
6 Warnings au total (Competitive) ou 5 (Professional) = Game Loss.

| Infraction fréquente | Sanction |
|---|---|
| Missed Trigger, Forgetting to Score/Draw/Ready | Aucune (l'adversaire choisit le remède) |
| Looking at / Drawing Extra Cards, Mispayment, trop de runes canalisées | Warning |
| Mulligan Procedure Error | Warning |
| Slow Play, Marked Cards, Insufficient Randomization | Warning |
| Decklist Error | Game Loss |
| Triche (angle shooting, triggers provoqués, stalling volontaire) | Disqualification |
